Student Mark List Management System Using Stack and Queue in C++
1. Introduction

The Student Mark List Management System is a data structure project developed using C++. It stores student details, including roll number, name, and marks. Stack and Queue are used to manage student records.

2. Objectives
To understand Stack and Queue data structures.
To store and manage student details and marks.
To implement insertion, deletion, and display operations.
To calculate student results based on marks.
3. Problem Statement

Managing student mark records manually can be time-consuming. This project demonstrates how Stack and Queue can be used to insert, process, remove, and display student records efficiently.

4. Data Structures Used
Stack

Stack follows the LIFO (Last In, First Out) principle.

Push: Add a student record.
Pop: Remove the most recently added student.
Display: Show records from the top of the stack.
Queue

Queue follows the FIFO (First In, First Out) principle.

Enqueue: Add a student record.
Dequeue: Remove the first student in the queue.
Display: Show student records in insertion order.
5. Technologies Used
Programming language: C++
Data structures: Stack and Queue
Standard library: C++ STL
Platform: GitHub
6. Modules
Add student to Stack.
Remove student from Stack.
Display Stack records.
Add student to Queue.
Remove student from Queue.
Display Queue records.
Display pass or fail status.
7. Expected Output

The program displays student roll numbers, names, marks, and pass/fail results. Stack records are processed in LIFO order, while Queue records are processed in FIFO order.

8. Applications
Student record management demonstrations.
Learning fundamental data structures.
Processing student entries in order.
Understanding LIFO and FIFO operations.
9. Conclusion

This project demonstrates the practical implementation of Stack and Queue using C++. It helps students understand data structure operations through a simple student mark list application.
